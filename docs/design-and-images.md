# Design and image credits

The site uses a photography-led layout with the Spark8Edge navy and gold, locally hosted Manrope type, and plain-language navigation. Training, finding talent and partnerships keep distinct paths to WhatsApp. The site describes an early-stage business; it does not present stock photography, an illustrative brief, or the founder’s earlier NGO work as proof of Spark8Edge client results.

Design references consulted via GitHub: [Anthropic Frontend Design](https://github.com/anthropics/skills/blob/e4bb5d960d87126ff3b3a8af1a104b7db67560ba/skills/frontend-design/SKILL.md) and [VoltAgent’s Airbnb design analysis](https://github.com/VoltAgent/awesome-design-md/blob/main/design-md/airbnb/DESIGN.md). For the later refresh, [Huini Studios](https://www.huinistudios.com/) informed the Nairobi-first editorial hierarchy and [ADMI](https://admi.africa/) informed the learner decision flow. No layout or copy was imported. About is intentionally image-free.
